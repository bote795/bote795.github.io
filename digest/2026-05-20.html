Act Now: Your VS Code Extensions Are a Supply Chain Attack

This is the item to act on before anything else today. A hijacked Nx Console extension (~2.2M installs) was used to harvest GitHub, npm, AWS, Kubernetes, and 1Password tokens from a GitHub employee's machine via an orphan commit which then gave attackers access to GitHub's own internal repos. The attack vector wasn't a zero-day; it was a trusted dev tool with millions of installs. Three concrete actions: (1) Rotate every secret in private repos, not just public ones attackers treat private repos as soft targets. (2) Audit and pin versions for every VS Code or Cursor extension you use. (3) Move secrets out of .env files into a dedicated secret manager. If you're running Cursor with extensions you installed months ago and never thought about again, today is the day to check.

Vendor Benchmarks Are Built to Win

The bias that shapes model behavior isn't in the prompt it's frozen into the weights at training time and can't be patched post-deployment. Researchers have documented this pattern by putting GPT-4o, Gemini, and Claude on downstream decisions: rating job candidates, security tools, medical chatbots. Each model rated options tied to its own company higher. When researchers relabeled the models through the API assigning each a competitor's identity, preferences flipped. Same weights, different label, different winner. The reflex to favor a side is trained in; the label just picks which side wins. This result sits underneath every major LLM-as-judge leaderboard built since 2023 AlpacaEval, MT-Bench, Arena-Hard. When Vendor A builds the evaluator and tests Vendor A's model, Vendor A wins because the evaluator recognizes its own family.

It also drifts without notice. Users have reported behavior changes across major model versions refusal patterns shifting around politically charged queries, DeepSeek's Taiwan answers updating, vendor sessions auto-migrating between model versions mid-run typically without accompanying changelogs. And switching to open-weight models doesn't fix it: DeepSeek R1 still refuses Tiananmen, Xinjiang, and Taiwan-as-country questions when self-hosted; the CCP-aligned priorities ride along in the base weights. Running the model on your own hardware moves the request off Chinese servers. The training doesn't move.

The working defense: cross-vendor any question that drives a real decision. Chase the primary source before trusting the summary. A benchmark published by the model's own lab is marketing with error bars.

Same-day recap of Google I/O 2026 announcements, focused on the developer and designer surfaces. The host walks through Gemini 3.5 (especially Flash for agentic coding), Anti-Gravity 2.0 (Google's IDE + CLI), Google AI Studio's new Workspace integration, Gemini Omni (video gen), Flow (cinematic editing), Stitch (in-browser Figma), and Pomelli (brand/marketing generation). Verdict: Google is playing visible catch-up to Anthropic/OpenAI on agentic coding, but the speed of Flash plus the multimodal/video creative tools are the differentiated bets — though many features either didn't ship on time or didn't work on the day.

Key takeaways:

  • Gemini 3.5 Flash is the speed-for-intelligence bet: Per Google's benchmarks it rivals Claude Opus 4.7 / Sonnet 4.6 intelligence but runs ~4x faster than those models — closer to prior-gen Flash speed. The pitch is "smart enough to do agentic work, fast enough that you don't have to wait."
  • Google is going fullbore on agents, even if it's catch-up: Anti-Gravity 2.0 ships sub-agents, hooks, scheduled tasks, git worktrees, and slash commands — all features Claude Code and Codex already have. The bet is speed + multimodal + creative surfaces are where they actually differentiate.
  • "Grill me" slash command is a hardcore PRD interrogator: An aggressive variant of Claude Code's clarifying-questions tool. Instead of polite clarification, the agent grills you on requirements until it has what it needs. Worth testing as a spec-tightening pattern. Mindset shift: Before: clarifying questions are friction. After: aggressive clarifying questions are a feature — they front-load the cost of vague specs.
  • Google AI Studio is going for the Workspace MCP turf: Native built-in Workspace integration (Sheets, Gmail, Drive, Calendar) inside the no-code app builder. The play is to own the personal-assistant / internal-tools use case before MCP connectors commoditize it — though as of taping, the host couldn't actually access the connectors.
  • Omni = Nano Banana for video: A reasoning model + video creation model that supports conversational edits, image-to-video, character consistency across scenes, and ~10s clips (longer than Sora's 6-7s). Production-grade editing is the explicit target, not novelty clips.

How to Use GPT Image 2 - 4 Real Workflows That Actually Work (@ThisWeekinAIPodcast)

Watch

A hands-on walkthrough of OpenAI's GPT Image 2, framed as "the first image model that thinks before it generates." The host demos four real workflows: brand kit generation with multi-turn iteration, photo relighting without reshooting, background object removal, and infographic generation from scratch. Core thesis: GPT Image 2 is unified into the GPT-4o architecture (not a bolted-on diffusion model), which is why text rendering, layout, and instruction-following finally work well enough to use in production.

Key takeaways:

  • GPT Image 2 is not a diffusion model — it's part of GPT-4o: Image understanding and generation share the same system. Before any pixel is drawn, the model plans composition and resolves ambiguity in your prompt. Mindset shift: Before: AI image models are bolted-on diffusion components that need careful prompts. After: image generation is just another modality of a reasoning model — write the prompt the way you'd brief a designer.
  • Text rendering is finally production-grade: Earlier models produced "text slop" with misspellings and garbled words. GPT Image 2 spells correctly and sizes text appropriately. This unlocks logos, infographics, banners, slides — anything text-bearing.
  • Multi-turn editing actually preserves brand state: You can generate a brand kit, then in a follow-up turn say "now make the Instagram post version with this tagline" and it holds the brand colors + logo while applying them to a new format. No re-prompting from scratch.
  • Relighting is the most underrated use case: Instead of reshooting a bad product photo or hiring a retoucher, prompt the model to relight the existing shot ("soft directional key light from upper left, warm rim light on the right edge, lift shadows"). Same image, new lighting, no studio cost.
  • Object removal is now one-shot good: "Remove all the people from the background, keep everything else the same" works cleanly. Some background hallucinations remain but the output looks real and crisp at first glance.
